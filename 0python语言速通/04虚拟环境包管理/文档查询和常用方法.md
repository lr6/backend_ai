## 高频内置函数

| 函数 | 作用 | JS 对应 |
|------|------|---------|
| `len(x)` | 长度 | `x.length` |
| `sum(arr)` | 求和 | `arr.reduce((a,b)=>a+b,0)` |
| `min(arr)` / `max(arr)` | 最小/最大 | `Math.min(...arr)` |
| `sorted(arr)` | 排序（返回新列表） | `arr.toSorted()` |
| `range(n)` | 生成 0~n-1 序列 | `[...Array(n).keys()]` |
| `enumerate(arr)` | 遍历带索引 | `arr.forEach((v,i)=>...)` |
| `zip(a, b)` | 两个列表配对 | 无直接对应 |
| `type(x)` | 看类型 | `typeof x` |
| `isinstance(x, t)` | 类型判断 | `x instanceof T` |
| `int(x)` / `str(x)` / `float(x)` | 类型转换 | `parseInt` / `String` |
| `any(arr)` / `all(arr)` | 任一为真 / 全部为真 | `arr.some()` / `arr.every()` |
| `round(n, d)` | 四舍五入 | `n.toFixed(d)` |
| `abs(x)` | 绝对值 | `Math.abs(x)` |
| `print()` | 打印 | `console.log()` |
| `input()` | 用户输入 | `prompt()` |

## 高频字符串方法

调用方式：`"abc".xxx()`

| 方法 | 作用 | JS 对应 |
|------|------|---------|
| `.split(sep)` | 分割 | `str.split()` |
| `.join(arr)` | 连接（在分隔符上调用） | `arr.join()` |
| `.strip()` | 去首尾空白 | `str.trim()` |
| `.startswith(s)` | 以 s 开头？ | `str.startsWith()` |
| `.endswith(s)` | 以 s 结尾？ | `str.endsWith()` |
| `.find(s)` | 查找子串位置，-1 表没找到 | `str.indexOf()` |
| `.replace(old, new)` | 替换 | `str.replace()` |
| `.lower()` / `.upper()` | 大小写 | `str.toLowerCase()` |
| `.isdigit()` | 是否全数字 | `/^\d+$/.test()` |

## 高频列表方法

调用方式：`[].xxx()`

| 方法 | 作用 | JS 对应 |
|------|------|---------|
| `.append(x)` | 末尾添加 | `arr.push()` |
| `.pop()` | 弹出末尾 | `arr.pop()` |
| `.extend(arr2)` | 合并列表 | `arr.concat()` |
| `.index(x)` | 查找索引 | `arr.indexOf()` |

| `.sort()` | 原地排序 | `arr.sort()` |
| `x in arr` | 是否包含 | `arr.includes(x)` |

## Q&A：pip 镜像与 venv 激活

### pip 中国大陆镜像

```bash
# 永久配置（已执行）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# 临时使用
pip install xxx -i https://pypi.tuna.tsinghua.edu.cn/simple
```

| 镜像 | 地址 |
|------|------|
| 清华 | `https://pypi.tuna.tsinghua.edu.cn/simple` |
| 阿里 | `https://mirrors.aliyun.com/pypi/simple` |
| 中科大 | `https://pypi.mirrors.ustc.edu.cn/simple` |

### venv 激活判断

**终端提示符**：激活成功后前面会出现 `(.venv)` 标记

**`which python`**：激活成功显示 `.venv/Scripts/python`，失败显示全局路径

**Git Bash 不生效的备选方案**：
```bash
# 不用 activate，直接用 venv 里的 Python
.venv/Scripts/python.exe your_script.py
.venv/Scripts/python.exe -m pip install xxx
```

### pip 安装位置

| 状态 | pip install 装到哪 |
|------|-------------------|
| 没激活任何 venv | 全局 Python 环境 |
| 激活了 `.venv` | 当前项目的 `.venv/` |
| 直接用 `.venv/Scripts/python.exe -m pip install` | 当前项目的 `.venv/` |
